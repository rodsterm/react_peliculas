# React Películas 🎬

Aplicación web desarrollada con React, Vite y `react-router-dom` para la visualización y gestión de películas favoritas.

## 🚀 Inicio Rápido

1. Instala las dependencias del proyecto:
   ```bash
   npm install
   ```

2. Ejecuta el servidor de desarrollo local:
   ```bash
   npm run dev
   ```
